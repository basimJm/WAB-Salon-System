## Facts

- Customer app is a KMP template (`WAB-Mobile-Customer/AGENTS.md`, `TECHSTACK.md`): Kotlin 1.10, Compose MP 1.10.3, Ktor 3.4.2, Koin 4.2.0.
- Tracked Firebase/iOS config files exist in `WAB-Mobile-Customer` (`google-services.json`, `GoogleService-Info.plist`, `Config.xcconfig`); review before making the repo public.
- Rules: `WAB-Mobile-Customer/CLAUDE.md` (Clean Architecture + MVI by delegate, no hardcoding, AR+EN, all variants, CI, <=300-line files, portrait+landscape). Module map there is real; `AGENTS.md` is generated and partly wrong.
- Variants: Android flavors `dev`/`prod` x `debug`/`release` (convention plugin `AndroidAppPlugin`, env values in `gradle.properties`, overridable in `local.properties`); iOS configs `Debug|Release-Dev|Prod`, schemes `iosApp-Dev|Prod`, `iosApp/Configuration/{Dev,Prod}.xcconfig` -> Info.plist -> `AppEnvironment` (Koin). Hosts are PLACEHOLDERS until the platform domain is decided. Dev uses the prod application id until a Firebase dev app exists (`DEV_APPLICATION_ID_SUFFIX`, `BUNDLE_ID_SUFFIX`).
- CI: `.github/workflows/customer-ci.yml` (policy, detekt, secret-scan, Android matrix, iOS matrix, `Customer CI passed`). Local: `WAB-Mobile-Customer/scripts/ci/run_local_checks.sh`; policy scripts + tests in `scripts/ci`; `policy_checks.py <file-length|hardcoded|quality|localization|variants|security|budget|all>`. Legacy debt: `config/policy-baseline.json` + `config/detekt/baseline.xml` (ratchet: may only shrink; `--update-baseline` after fixing).
- Sandbox limits: `dl.google.com` (Android SDK, Google Maven, AGP) is blocked by the egress policy, so Android/iOS Gradle builds cannot run on the cloud runner; CI is the compiler. Maven Central mirror that works: `https://maven-central.storage-download.googleapis.com/maven2` (repo.maven.apache.org rate-limits with 429). Design-system code is checked on a desktop-JVM scratch harness.
- Design system (T-029/T-030): `core/design-system` = tokens in `theme/` (read via `AppTheme.colors|spacing|shapes|typography|sizes|elevation|alpha|motion|adaptive`), components under `components/*` (all `App*`), icons via `AppIcons` (Material icons, auto-mirrored), fonts in `composeResources/font`. Adaptive: `AppWindowSize` -> `AdaptiveTokens` (bottom bar vs rail, grid columns). Colors for text on tinted containers are `on*Container` roles (WCAG). Component logic is pure functions with tests (`countBadgeLabel`, `starFill`, `stepState`, `sanitizeOtp`, `initialsOf`).
- Design source of truth: `design/*.dc.html` uses a VIOLET theme (#6D28D9 / #A855F7 gradient, ink #1F2233, dark bg #14172B; Playfair Display + Poppins + IBM Plex Sans Arabic; radii 14/16/26). The Kotlin template theme (emerald "Stitch") is NOT the product design; the design script says keep the existing design theme and logo.
- Auth refresh (T-031): `TokenRefreshCoordinator` (core/network/auth, single-flight) + `installAuthRefresh` (HttpSend interceptor in `client/AuthRefreshInterceptor.kt`); refresh endpoint path is an ASSUMPTION in `AuthEndpoints` until SRV-026/INT-01. Only a rejected refresh ends the session. Tests need `kotlinx-coroutines-test`.
- Permissions (T-032): `PermissionFlow.ensure(AppPermission)` in `core/ui/permission` (Koin `permissionModule`); Android needs `MainActivity` to attach `AndroidPermissionBridge` (done); iOS manager uses UserNotifications/AVFoundation/CoreLocation. Screens show a settings prompt for `BlockedInSettings`.
- Appearance (T-033): inject `AppearanceSettings` (core/domain) for language/theme: `language: Flow<AppLanguage>` (Arabic default, `isRtl`, `fromCode` tolerates `ar_JO`), `themeMode`, `setLanguage`, `setThemeMode`, `toggleLanguage()`. `App.kt` takes direction and locale from it.
