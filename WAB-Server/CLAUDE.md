# WAB-Server

Backend API: Node + Express + Mongoose + Redis + Socket.IO + BullMQ, TypeScript strict. Module map: `python3 ../scripts/map.py server`.

- **Before your first code edit:** read `docs/ENGINEERING_RULES.md` once.
- **Next task:** `python3 ../scripts/tasks.py next server`.
- **Requirements, by section only (grep the heading, read that range):** `docs/WAB_Backend_BRD.md`, `../BUSINESS_DOMAIN.md`.
- **Gate:** `npm run verify` (test suites with supertest or Redis need the Terminal panel).
- Every endpoint change: `npm run docs`, then `npm run contract:bump -- <namespace> "<client tasks>"`, then `npm run docs` again.
- **Older task blocks and facts:** `docs/knowledge/`, searched with `python3 ../scripts/recall.py <words>`.
