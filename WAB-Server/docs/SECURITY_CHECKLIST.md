## Known gaps and decisions

- **HTTPS and backups** are hosting concerns; they are closed by SRV-011 / SRV-116 once the owner decides the platform.
- **Dependency scan in CI** was removed on the owner's request; the local gate replaces it. Re-add `npm audit --omit=dev --audit-level=high` to a workflow if CI returns.
- **Guest installation tokens**: a guest request can overwrite the push token of an installation id it knows (ids are random, unguessable Firebase instance ids). A signed per-install secret would close it (SRV-033 note).
- **Access tokens are not revocable** before expiry (15 minutes); revocation is by refresh-token family (SRV-025 note).
- **Customer and merchant route protection** is proven per feature (401/403 cases in each feature's tests) and by the scope matrix in `tests/auth.test.ts`; only the admin namespace has the all-routes audit, because its guard is one shared middleware.
