### Mobile Number Format

- `0788123456` → Stored as `+962788123456`
- Validation: Must match `/^07[7-9]\\d{7}$/`

### OTP Flow

- **Development:** OTP is always `0000`
- **Production:** Random 4-digit (SMS integration TBD)
- **Expiry:** 10 minutes
- **Storage:** Separate `MobileVerification` collection (TTL index auto-cleans after 10 min)

## Endpoints Summary

### GET `/health`
Check if the server is running

### POST `/v1/customer/auth/register`
Generate and send OTP to the provided mobile number.

In development, OTP is always **0000**.
In production, OTP will be sent via SMS (3rd party integration TBD).
This does NOT create a user — only generates and stores OTP.

**Body Parameters:**
- `firstName` (string, required) — Min 3 characters
- `lastName` (string, required) — Min 3 characters
- `email` (string, required) — Valid email format
- `mobile` (string, required) — Jordanian mobile starting with 07[7,8,9]
- `image` (file, optional) — JPEG/PNG/WebP, max 5MB (multipart)

### POST `/v1/customer/auth/verify`
Verify OTP and receive JWT access token.

If user does NOT exist: creates a new verified user with role 'customer' and returns JWT.
If user already exists: verifies OTP and returns a new JWT (login flow).

**Body Parameters:**
- `mobile` (string, required) — Must match the number used in register/login
- `otp` (string, required) — 4-digit OTP (0000 in development)

### POST `/v1/customer/auth/login`
Generate and send OTP for an existing registered user.

User MUST already exist (registered and verified).
After getting OTP, call /verify with the OTP to receive a JWT.

**Body Parameters:**
- `mobile` (string, required) — Registered Jordanian mobile number

### POST `/v1/notifications/device-token`
Register a mobile FCM push token for the authenticated user.

Requires Authorization: Bearer <JWT>.
Upserts by token — registering again refreshes the owner/platform.
Emits a realtime 'notification' event to the user's socket room on success.

**Body Parameters:**
- `token` (string, required) — FCM device token, min 20 characters
- `platform` (string, optional) — ios | android | web (default android)
